# AgriMithra (అగ్రిమిత్ర)
Voice AI assistant for Indian farmers who cannot read or type.

## Problem
Millions of farmers lack timely, trusted advice in their own language.
Most apps need reading, typing and English.

## What this prototype does
- Voice question in Telugu, Hindi, Tamil or English
- AI answer spoken back in the same language, in simple words
- Photo upload: crop leaf disease or pesticide label, with safety steps
- Remembers the farmer's profile (village, land, crops)

## How to run
1. Open the live link (or open index.html in Google Chrome)
2. Get a free API key at aistudio.google.com/apikey and paste it in the box
3. Tap the mic and ask a question

## Tech
HTML/JavaScript, browser speech recognition and speech synthesis, Google Gemini API

## Roadmap

- Live mandi prices and weather alerts
- Local KVK / agriculture officer connection
